# PvZ-Modifier - 植物大战僵尸内存修改器（MFC / C++）
# 使用版本链接：[植物大战僵尸融合版3.0.1](https://b23.tv/SZy90he)

> 通过直接修改游戏进程内存，实现“无限阳光”、“植物无冷却”、“植物0消耗”等效果，学习 Windows 进程内存操作原理。

本工具基于 MFC 开发，通过定位游戏内存地址并调用 `WriteProcessMemory` 实现动态修改，是理解游戏外挂原理与内存调试技术的理想实践项目。

## 🔧 核心功能
- ✅ **获取阳光值**：实时读取游戏内当前阳光数值
- ✅ **修改阳光值**：可自定义设置任意阳光数量
- ✅ **无冷却**：使所有植物种植后立即可再次使用
- ✅ **植物0消耗**：种植植物时不再消耗阳光

## 🛠️ 技术实现
- **开发框架**：MFC (Microsoft Foundation Classes)
- **内存操作**：
  - 使用 `Cheat Engine` 定位关键内存地址（如阳光值、冷却计时器）
  - 调用 `OpenProcess` + `ReadProcessMemory` / `WriteProcessMemory` 实现读写
  - 支持“刷新”功能，动态更新当前游戏状态
- **UI 设计**：标准对话框界面，按钮清晰，操作直观

## 💡 学习目标
- 掌握游戏内存结构分析方法
- 理解 Windows 进程权限与句柄机制
- 实践 API 调用与数据类型转换（int/float）
- 体验“外挂”背后的底层技术原理

## 📌 使用说明
1. 启动《植物大战僵尸》游戏
2. 以**管理员权限**运行本程序
3. 点击【刷新】按钮，读取当前阳光值
4. 修改数值或点击功能按钮即可生效

> ⚠️ 注：本项目仅用于技术学习与逆向分析研究，不用于破坏游戏平衡或商业用途。
